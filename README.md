# MoveNear MVP (Android/iOS)

MoveNear — MVP мобільної платформи для доступних попутних поїздок у межах міста та між містами.

## 1) Аналіз схожих сервісів

### Uber / Bolt / Uklon
- Сильні сторони: швидке бронювання, трекінг, оплата в застосунку.
- Слабкі сторони: surge pricing під час піків, фокус на “двері-в-двері”, що збільшує вартість.
- Наша відмінність: режим **наближеної точки** (200м/1км/2км) для суттєвого зменшення ціни.

### BlaBlaCar
- Сильні сторони: міжміські поїздки, зрозуміла механіка попутників.
- Слабкі сторони: менша ефективність для мікро-маршрутів у місті “тут і зараз”.
- Наша відмінність: об’єднання short-hop і long-distance в одному UX + live геоочікування.

### inDrive
- Сильні сторони: гнучкість ціни.
- Слабкі сторони: ціна не завжди прозоро рахується, часто затягнутий матчинг.
- Наша відмінність: глобальна формула тарифу (дистанція + територія + клас транспорту), менше хаотичних торгів.

### Hitchhiking / локальні чати
- Сильні сторони: низька ціна або безкоштовно.
- Слабкі сторони: низька безпека, відсутність верифікації та гарантованого платежу.
- Наша відмінність: KYC, рейтинги, вбудована оплата, маршрутна прозорість.

## 2) Продуктова концепція

### Режими
1. **NearRide (місто):** пасажир задає приблизну точку висадки й радіус (200м/1км/2км).
2. **LongRide (міжмісто):** пасажир бронює місце у водія/перевізника за напрямком.
3. **Bus Spare Seats:** далекомагістральні автобуси публікують вільні місця в реальному часі.

### Цінова модель (MVP)
- Базовий тариф + тариф/км + коефіцієнт зони + коефіцієнт класу авто.
- Знижка за “гнучку висадку” (чим більший радіус — тим дешевше).
- Комісія платформи утримується автоматично в платежі.

### Безпека
- Реєстрація з документами (KYC-готова модель даних).
- Пасивний GPS-трекінг активної поїздки.
- Рейтинг водія/пасажира після завершення.

## 3) Що реалізовано в цьому репозиторії

- **Mobile (Expo React Native):**
  - Glassmorphism (“Apple glass”) дизайн.
  - Вибір режиму NearRide/LongRide.
  - Вказання дистанції, радіуса, класу авто.
  - Розрахунок ціни через бекенд.
  - Оплата через Stripe Payment Sheet.
- **Backend (Node.js + Express + SQLite):**
  - API оцінки вартості (`/api/quote`).
  - API створення бронювання (`/api/rides`).
  - API списку активних поїздок (`/api/rides/active`).
  - API ініціалізації платежу (`/api/payments/intent`).
  - Збереження rides/users/reviews.

## 4) Швидкий запуск

### Backend
```bash
cd backend
cp .env.example .env
npm install
npm run dev
```

### Mobile
```bash
cd mobile
cp .env.example .env
npm install
npm run start
```

> Для оплати вкажіть Stripe ключі в `.env` (backend + mobile).

## 5) Наступні кроки після MVP

- KYC провайдер (Onfido / Sumsub).
- WebSocket/Realtime матчинг і ETA.
- Push notifications (pickup/update/cancel).
- Escrow/partial refund логіка.
- Антифрод скоринг.
